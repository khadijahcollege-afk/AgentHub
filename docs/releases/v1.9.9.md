# AgentHub 1.9.9

Statistik pemakaian berhenti menyalahkan model yang sehat.

## Masalahnya

Versi 1.9.8 memperbaiki rotasi Free Auto: model yang belum mengeluarkan output
sampai tenggat sekarang hanya dijeda singkat, bukan dikarantina 10 menit.

Tetapi angka yang dilihat pengguna belum ikut berubah. Harness CLI mencatat
**setiap** abort sebagai kegagalan:

```js
if (killed === 'abort') { bumpStat(engineId, { failed: 1 }); return reject(abortError()); }
```

Abort itu bisa datang dari tiga sebab yang sama sekali berbeda: pengguna menekan
Stop, run dibatalkan karena percakapan diganti, atau — kasus yang memicu
investigasi ini — model belum mengeluarkan apa pun sampai tenggat. Ketiganya
tercatat sama: `failed`.

Akibatnya pane Pemakaian menampilkan engine yang benar-benar menjawab sebagai
"gagal". Di mesin ini `engine-stats.json` berisi:

```json
"opencode-free-flint-40b-free": { "runs": 1, "ok": 0, "failed": 1 }
```

Padahal Flint menjawab `SIAP` dalam 26,7 detik saat dijalankan manual. Angkanya
menyesatkan ke arah yang paling mahal: orang berikutnya akan memeriksa modelnya,
bukan ambang waktunya.

## Yang berubah

- **`slow` jadi angka sendiri.** Abort dengan alasan `slow` dihitung `slow: 1`,
  bukan `failed: 1`. Kegagalan sungguhan — exit code bukan nol, CLI tidak
  terpasang, run melewati batas 10 menit — tetap dihitung `failed`.
- **Alasan pembatalan dibawa, bukan ditebak.** `AbortSignal.abort('slow')`
  diteruskan ke `killTree()`, lalu ke `abortError(reason)`. Tanpa alasan ini
  harness tidak punya cara membedakan "pengguna menekan Stop" dari "model terlalu
  lama diam", dan keduanya akan selamanya tercatat sama.
- **UI dan ekspor ikut jujur.** `/api/usage` melaporkan `slow`; baris pemakaian
  menampilkan "N lambat" hanya bila angkanya ada (tidak menambah kebisingan untuk
  engine yang tidak pernah lambat); header CSV bertambah kolom `slow`, sehingga
  ekspor tidak menghilangkan perbedaan yang sudah dibuat di layar.
- **Label dua bahasa.** Kata "lambat" masuk kamus Indonesia–Inggris, jadi UI
  berbahasa Inggris menampilkan "slow", bukan kata Indonesia di tengah kalimat
  Inggris.

## Penjaga

Tes server Free Auto sekarang memeriksa tiga hal setelah model lambat benar-benar
diputar: `engine-stats.json` di disk (`slow: 1`, `failed: 0`), `/api/usage`
(angka yang sama sampai ke klien), dan header CSV (kolom `slow` ada). Diuji
dengan tiga mutasi yang mengembalikan cacatnya: 3/3 tertangkap.

## Catatan

Angka lama di `engine-stats.json` tidak diubah. Isinya riwayat; menulis ulang
riwayat agar terlihat benar bukan perbaikan, melainkan penghapusan bukti. Hitungan
baru mulai berlaku sejak versi ini.

Installer AgentHub belum ditandatangani secara digital. Windows akan menampilkan
peringatan SmartScreen pada pemasangan pertama.

Suite: 672 tes, hijau.
