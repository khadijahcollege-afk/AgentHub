## What's new

- Refreshed desktop workspace with a dark/orange theme, SVG icons, responsive navigation, clearer Settings and About pages, and an improved Orchestra view.
- Persistent usage statistics: activity cards, yearly heatmap, 7/30/90-day charts, and breakdowns by feature and engine.
- Separate Indonesian/English interface language and agent reply-language preferences.
- Automatic sign-in when opening the dashboard directly on localhost. Phone access uses the token included in the pairing QR link.
- Clear Android, iPhone, and web setup instructions. The dashboard runs on your AgentHub server; full PWA support requires HTTPS.
- Fixed Windows CLI argument handling so spaces, quotes, multiline prompts, and long prompts reach installed agent harnesses correctly.
- Fresh desktop and mobile screenshots in both READMEs, plus corrected cross-platform installer packaging.

## Downloads

| Platform | Package |
|---|---|
| Windows 10/11 x64 | `AgentHub-Setup.exe` — desktop installer with tray integration |
| Windows portable | `AgentHub-Portable.zip` — extract and run `Start AgentHub.bat` |
| macOS | `AgentHub-macOS.dmg` or `AgentHub-macOS-portable.zip` |
| Linux | `AgentHub-linux.AppImage` or `AgentHub-linux.deb` |
| Android / iPhone | Open your running server through the pairing QR; see the [mobile guide](https://khadijahcollege-afk.github.io/AgentHub/#web-mobile) |

The macOS packages are unsigned; use the system's Open option on first launch. Keep the host computer running for phone access. `SHA256SUMS.txt` contains checksums for all six downloads.
