# AgentHub 1.9.5

Preset Z.ai berhenti menagih dua kali.

Ada tiga pintu ke GLM di Z.ai, dan tagihannya berbeda:

| Pintu | Base URL | Yang dipotong |
|---|---|---|
| Coding Plan (OpenAI) | `api.z.ai/api/coding/paas/v4` | kuota langganan |
| Coding Plan (Anthropic) | `api.z.ai/api/anthropic` | kuota langganan |
| API bayar per token | `api.z.ai/api/paas/v4` | saldo, terpisah dari plan |

Sampai 1.9.4 hanya ada satu preset `zai` berlabel "Z.ai (GLM Plan)" yang
menunjuk ke pintu **ketiga**. Komentarnya sendiri mengklaim preset itu "sumber
kuota plan", tetapi URL-nya endpoint yang menagih per token. Key langganan yang
ditempel di sana tidak pernah menyentuh kuota plan — dan tidak ada satu pun
tanda di UI bahwa yang terjadi adalah itu.

## Yang berubah

- **Tiga preset, bukan satu.** `zai` sekarang Coding Plan lewat protokol
  OpenAI, `zai-anthropic` Coding Plan lewat protokol Anthropic, dan `zai-api`
  tetap ada untuk yang memang ingin membayar per token — dengan label yang
  menyebutnya terang-terangan.

- **Preset menentukan protokolnya.** Sebelumnya `addKey` selalu jatuh ke
  `chat_completions`, jadi key yang dimasukkan lewat preset Anthropic akan
  mengirim body OpenAI ke `/messages` dan ditolak sebagai permintaan rusak.
  Sekarang preset membawa `format` dan UI mengikutinya saat dipilih; nilai
  eksplisit dari pemanggil tetap menang.

- **Probe key membaca isi body, bukan hanya status HTTP.** Z.ai membalas
  **HTTP 200** dengan `{"code":1000,"success":false}` untuk key yang ditolak.
  Pemeriksaan lama hanya melihat `res.ok`, sehingga hasilnya "Key valid ·
  0 model" — key yang tidak bisa dipakai dilaporkan sehat, dan kegagalannya
  baru muncul saat agent benar-benar memanggil. Sekarang `success:false` dan
  kode non-nol diperiksa; kegagalan yang menyebut auth jadi `invalid` (dibuang
  dari pool), kegagalan lain jadi `error` (tetap dicoba, karena key belum tentu
  salah).

## Tentang jam malam

Jam sibuk Z.ai adalah Senin–Jumat 14:00–18:00 SGT (UTC+8). Untuk WIB itu
13:00–17:00, jadi mulai **17:00 WIB** tarifnya sudah setengah. Diskon off-peak
berlaku di semua tool resmi, bukan hanya ZCode — yang eksklusif ZCode hanya
bonus pengali 1,5× dan kampanye Flash malam.

## Catatan

Installer AgentHub belum ditandatangani secara digital. Windows akan
menampilkan peringatan SmartScreen pada pemasangan pertama.

Pemasangan pertama di mesin ini tetap perlu satu kali manual, karena aplikasi
yang terpasang masih 1.6.13 yang belum punya fitur pembaruan. Sesudah versi ini
terpasang, tombol **Cek pembaruan** menyelesaikan seluruh rantainya sendiri.
