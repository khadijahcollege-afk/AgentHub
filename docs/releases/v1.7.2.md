## What's new

Two stages that both answer the same complaint: work that is already done
disappearing from view.

- **Context summary.** The pool engine only ever sent the last 12 messages to the
  model, so past twelve turns the beginning of a conversation vanished with no sign
  in the UI — and the model re-litigated decisions it had already agreed to. Older
  turns now fold into one fenced note, the newest 6 are always sent verbatim, and
  the folded turns are no longer sent alongside their summary. Summaries nest
  (the previous one feeds the next), and the cursor only advances when a summary
  actually succeeded, so a dead pool leaves your history untouched. **Drop summary**
  restores the full conversation without deleting a single message.
- **Terminal tabs.** A tab is a separate session, so a second tab never overwrites
  the first one's output. Numbers are stable and reuse the smallest free one:
  `folder`, `folder 2`, `folder 3` — and open tabs are never renumbered, because a
  tab whose name changes is a tab you lose track of. Closing the **panel** only
  hides it; only closing a tab ends its session, so `npm test` keeps running while
  you read code. The tab list lives in the server, so a reload or a workspace switch
  finds the running command instead of an empty terminal.
- **Real exit codes in the terminal.** A bug this stage's tests caught:
  `powershell.exe -Command` reports 1 for *every* failure, so a command that exited
  with 3 looked like 1. The wrapper now ends with `exit $LASTEXITCODE`, falling back
  to `$?` for cmdlets — which matters exactly when you are reading CI output.

Both features are off or inert by default in the way that costs nothing:
automatic summarization is a setting (`compactAuto`), and the terminal still runs
one command per process — it is not a PTY, so interactive programs are not
supported yet. That limit is stated in the UI rather than hidden.

Validated with the complete 459-test regression suite, plus UI audits at
1440/1024/390/320 in both languages. See
[CHANGELOG.md](https://github.com/khadijahcollege-afk/AgentHub/blob/v1.7.2/CHANGELOG.md)
for details.
