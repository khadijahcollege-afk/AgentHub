## What's new

AgentHub now behaves like an agent, not a chat box. This release is the result
of reading through ZCode (Apache-2.0) and porting the contracts that make an
agent safe to leave running — not its looks.

- **A real tool loop.** The model is given eight built-in tools (read, write,
  edit, delete, list, grep, run a command, ask a question), calls them, reads
  the results, and continues until it finishes or hits the round limit.
- **Permission modes that actually stop.** `plan` reads only, `build` asks
  before writing, `edit` writes but asks before commands, `guarded` asks only
  for dangerous commands, `yolo` never asks. When a mode says *ask*, the run
  genuinely pauses and a card appears above the composer — it no longer denies
  the tool and leaves you guessing.
- **Answers are guaranteed to end.** Every request finishes by an answer, a
  timeout (3 minutes for permission, 10 for a question), Stop, or shutdown.
  "Always allow in this folder" exists for file writes only — never for shell
  commands, because one harmless command does not make the next one safe.
- **`AskUserQuestion`.** The agent can ask decisions that must not be guessed:
  1–4 questions, 2–4 options, single or multi-select, plus a free-text answer.
  Validated before a card is ever drawn.
- **A waiting run survives a reload.** Closing the tab or refreshing the page
  no longer kills a pending question; the card comes back in the new tab and
  the run continues when you answer.
- **Checkpoints.** Every turn snapshots the files it is about to change, so one
  step can be undone without touching git staging.
- **Hooks (9 events), MCP servers, plugins, standing instructions, automatic
  memory, and subagents** — a subagent always inherits a mode no looser than
  its parent and reports back instead of cluttering the conversation.
- **Read-only conversation links** with expiry and revocation; the access token
  never reaches the shared page.

## Downloads

| Platform | Package |
|---|---|
| Windows 10/11 x64 | `AgentHub-Setup.exe` — desktop installer with tray integration |
| Windows portable | `AgentHub-Portable.zip` — extract and run `Start AgentHub.bat` |
| macOS | `AgentHub-macOS.dmg` or `AgentHub-macOS-portable.zip` |
| Linux | `AgentHub-linux.AppImage` or `AgentHub-linux.deb` |
| Android / iPhone | Open your running server through the pairing QR; see the [mobile guide](https://khadijahcollege-afk.github.io/AgentHub/#web-mobile) |

The macOS packages are unsigned; use the system's Open option on first launch. Keep the host computer running for phone access. `SHA256SUMS.txt` contains checksums for all six downloads.

## Bahasa Indonesia

AgentHub kini benar-benar bertindak, bukan hanya menjawab. Delapan tool bawaan
(baca, tulis, edit, hapus, daftar, cari, jalankan perintah, bertanya) dijalankan
dalam loop sampai pekerjaan selesai. Mode izin menentukan apa yang butuh
persetujuan — dan ketika mode berkata *tanya*, run berhenti sungguhan lalu
menampilkan kartu di atas composer, bukan menolak diam-diam. Setiap permintaan
pasti berakhir: dijawab, batas waktu, tombol Stop, atau proses dimatikan.
"Selalu di folder ini" hanya untuk penulisan berkas, tidak pernah untuk
perintah shell.

`AskUserQuestion` membuat agent bisa menanyakan keputusan yang tidak boleh
ditebak. Permintaan yang menunggu bertahan dari muat ulang halaman: kartunya
kembali dan run lanjut saat Anda menjawab. Setiap putaran juga menyimpan salinan
berkas yang akan berubah (checkpoint), jadi satu langkah bisa dibatalkan tanpa
menyentuh staging git. Ditambah hook 9 event, server MCP, plugin, instruksi
tetap, memori otomatis, subagent, dan tautan percakapan baca-saja.

Validated with the complete 424-test regression suite. See [CHANGELOG.md](https://github.com/khadijahcollege-afk/AgentHub/blob/v1.7.0/CHANGELOG.md) for details.
