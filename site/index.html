Use AgentHub on Android, iPhone, or the web

The dashboard runs in your browser. Start AgentHub on your computer and keep it running, then open its dashboard URL. This website provides downloads and instructions; your dashboard is hosted by your own AgentHub server.

Web browserOn the host computer, open http://localhost:7788 (default port). On another device, use the dashboard URL or scan the QR in Settings → Phone. The QR includes your access token.
AndroidOpen the QR link in Chrome. For an installed PWA, use an HTTPS dashboard URL, then choose Install app or Add to Home screen from the browser menu.
iPhone / iPadOpen the QR link in Safari, then tap Share → Add to Home Screen. Use HTTPS for full PWA support. There is currently no separate App Store or APK download.

For local Wi-Fi access, the phone and computer must share a network. For access over mobile data and an HTTPS URL, enable the optional tunnel in Settings (requires cloudflared). PWA offline support covers the interface; agents still require the running server.

Free promo tracking

Three live sources (OpenRouter, models.dev, GitHub free-tier list) plus a curated catalog — with alerts + Windows toasts when new free models appear.

Gateway Pool

One OpenAI-compatible endpoint for every agent. Quota exhausted (429)? Traffic fails over to the next free provider automatically.

Agent connectors

n8n/Make/custom webhooks and OpenAI-compatible LLM endpoints — scheduled health checks with status history.

Monitor from your phone

Scan a QR and open the same dashboard on your phone over Wi-Fi — realtime, token-protected.

Privacy

Everything runs and stays on your machine. No cloud, no telemetry. API keys are sent only to the providers you use.

Featherweight

Pure Node.js with zero npm dependencies — small memory footprint even while idle.
