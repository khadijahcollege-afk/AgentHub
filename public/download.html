AgentHub untuk Windows

Installer lengkap (termasuk Node.js runtime — tidak perlu install apa-apa lagi). 23 MB.

⬇️ Unduh InstallerAgentHub-Setup.exe · Windows 10/11 64-bit
1 · UnduhKlik tombol unduh di atas, simpan file installer.
2 · JalankanBuka installer → Next → Install. Bila Windows menanya izin, pilih Yes.
3 · PakaiAgentHub terbuka otomatis. Shortcut ada di Start Menu & Desktop.
📦 Versi portable (ZIP, tanpa install) Autostart opsional saat install

Versi lain belum dipaketkan. Karena AgentHub berjalan dengan Node.js, Anda bisa menjalankan sumbernya langsung:

git / salin folder AgentHub
node server.js        # butuh Node.js 18+

UI web-nya responsif — dari Linux/macOS tetap bisa dibuka di browser & HP.

💡 Sudah terinstall di komputer ini? Dari HP yang 1 WiFi dengan komputer, buka dashboard lalu pindai QR — tanpa install apa pun di HP. Halaman unduh ini bisa dibuka dari komputer lain di jaringan yang sama: http://<ip-komputer>:7788/download
