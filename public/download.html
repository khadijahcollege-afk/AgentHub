AgentHub untuk Windows

Aplikasi desktop native (jendela + tray) dengan runtime tergabung — sekitar 82 MB.

Unduh InstallerAgentHub-Setup.exe · Windows 10/11 64-bit
1 · UnduhKlik tombol unduh di atas, simpan berkas installer.
2 · JalankanBuka installer, lalu Next → Install. Bila Windows menanyakan izin, pilih Yes.
3 · PakaiAgentHub terbuka otomatis. Shortcut tersedia di Start Menu dan Desktop.
Versi portable (ZIP, tanpa install) Autostart opsional saat install

Versi lain belum dipaketkan. Karena AgentHub berjalan dengan Node.js, Anda bisa menjalankan sumbernya langsung:

git / salin folder AgentHub
node server.js        # butuh Node.js 18+

UI web-nya responsif — dari Linux/macOS tetap bisa dibuka di browser dan HP.

AgentHub di Android, iPhone, dan browser

Versi web berjalan dari server AgentHub di komputer Anda. Jalankan AgentHub dan biarkan komputer menyala, lalu buka dashboard. Belum ada unduhan APK atau aplikasi App Store terpisah.

Buka dashboard server ini
BrowserDi komputer server, buka http://localhost:7788 (port bawaan). Dari HP atau perangkat lain, pindai QR di Pengaturan → Telepon. QR sudah menyertakan token akses.
AndroidBuka tautan QR di Chrome. Untuk memasang PWA, gunakan URL dashboard HTTPS, lalu pilih Instal aplikasi atau Tambahkan ke layar utama dari menu browser.
iPhone / iPadBuka tautan QR di Safari, lalu pilih Bagikan → Tambahkan ke Layar Utama. Gunakan HTTPS untuk dukungan PWA penuh.

Akses lokal memerlukan WiFi yang sama. Untuk data seluler dan URL HTTPS, aktifkan tunnel opsional di Pengaturan (memerlukan cloudflared). Cache offline menyimpan antarmuka; agent tetap memerlukan server yang berjalan.

Sudah terinstall di komputer ini? Dari HP yang tersambung ke WiFi yang sama, buka dashboard lalu pindai QR — tanpa install apa pun di HP. Halaman unduh ini juga bisa dibuka dari komputer lain di jaringan yang sama: http://<ip-komputer>:7788/download

Promo & token gratis

Tiga sumber live (OpenRouter, models.dev, GitHub) plus katalog — alert saat ada model gratis baru.

Gateway Pool

Kuota satu provider habis? Otomatis pindah ke berikutnya. Agent tetap hidup dari token gratis.

Konektor agent

Webhook n8n/Make/custom dan endpoint LLM — health check otomatis plus riwayat status.

Pantau dari HP

Dashboard yang sama di HP lewat QR, update realtime, dilindungi token.

Privasi

Data dan API key tersimpan lokal di komputer Anda. API key dikirim hanya ke provider yang Anda gunakan.

Ringan

Node.js murni tanpa framework berat — saat idle jejak memorinya kecil.
