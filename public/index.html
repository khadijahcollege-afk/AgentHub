Memori agent

            
Fakta tetap yang otomatis disuntikkan ke setiap prompt — ala Memory di ChatGPT atau CLAUDE.md di Claude Code. Semua tersimpan lokal (memory.json); isi prompt dikirim hanya ke provider yang sedang dipakai.

            
            
            
Satu panggilan model tambahan per percakapan, hanya setelah run berhasil. Fakta berbentuk perintah, prompt-marker, atau kredensial selalu dibuang. Maksimal tiga fakta per run. Tombol Ekstrak sekarang membaca seluruh percakapan yang sedang dibuka, jadi ia juga mengejar fakta dari sebelum fitur ini dinyalakan.

            

              
              
            

            

            

              
              
            

            


            
Ringkasan konteks

            
            
Percakapan panjang hanya mengirim 12 pesan terakhir ke model, sehingga keputusan di awal thread hilang tanpa jejak. Ringkasan menggantikannya: pesan lama dilipat menjadi satu catatan, sedangkan pesan terbaru tetap dikirim apa adanya. Satu panggilan model per ringkasan, berjalan setelah run selesai dan hanya bila percakapannya sudah cukup panjang. Bisa juga dijalankan manual lewat /compact.

          


          

            
Instruksi tetap

            
Teks di bawah dikirim ke model sebelum pesan Anda, di setiap percakapan. Berguna untuk preferensi gaya kerja yang berlaku terus-menerus. Urutan yang dikirim: instruksi pengguna ini, lalu aturan proyek (AGENTS.md/CLAUDE.md di folder kerja), lalu instruksi khusus thread.

            
Berkas: AGENTS.md

            
            

              
              
              
            

            

          


          

            
Server MCP

            
Model Context Protocol memberi agent tool dari luar AgentHub — GitHub, database, browser, apa pun yang menyediakan server MCP. Tool-nya muncul untuk model dengan nama mcp__<server>__<tool>. Kredensial (header/env) tidak pernah ditampilkan kembali oleh API.

            

            

              
              
              
              
              
              
              

                
                
                
              

            

          


          

            
Hook siklus hidup

            
Hook adalah program lokal yang dijalankan pada event agent: SessionStart, UserPromptSubmit, PreToolUse, PermissionRequest, PostToolUse, PostToolUseFailure, Stop. Hook menerima JSON di stdin dan boleh membalas JSON; exit code 2 memblokir. Hook dari folder proyek hanya berjalan setelah Anda menyetujui digest deklarasinya.

            
            

              
              
              
              
              

            

            

            

          


          

            
Plugin

            
Satu paket bisa membawa skill, perintah slash, hook, dan server MCP sekaligus. Skill dan perintah hanya teks — tidak menambah izin. Hook dan server MCP adalah kode yang benar-benar dijalankan, jadi keduanya baru aktif setelah Anda menyetujui digest-nya. Mengubah isi skrip plugin otomatis mencabut izin lama.
