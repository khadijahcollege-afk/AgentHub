Buat dokumentasi endpoint dari kode yang diberikan (@sebutkan berkas).

Per endpoint keluarkan:
## METHOD /path
- Deskripsi satu kalimat.
- Parameter: tabel | nama | tipe | wajib | ket |
- Respons: kode + bentuk body (contoh JSON ringkas).
- Contoh curl satu baris.
Sumber hanya kode yang benar-benar ada. Jangan mengarang rute.
